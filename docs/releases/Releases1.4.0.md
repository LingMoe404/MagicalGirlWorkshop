# v1.4.0 - 魔法少女工坊：多重炼成，动态并发

> “让强大的显卡同时照看多条炼成回路，也让每一次降级都有明确理由。”

**魔法少女工坊 v1.4.0** 将无人值守稳定性修复与新的多文件并发架构合并发布。本次更新不仅修复了 NVIDIA 远程桌面锁屏后 DXVA2 设备失效、字幕错误误判和 ab-av1 临时结果误用，还加入了适用于 Intel QSV、NVIDIA NVENC 与 AMD AMF 的动态多路转码。

## 版本亮点

### 多路文件转码

- 手动模式支持固定 `1–4` 路并发。
- 自动模式从 `1` 路开始，根据实际吞吐量与系统资源逐步尝试提升，最高 `3` 路。
- 探测、正式编码、输出落盘与冷却属于同一个任务周期，整个周期持续占用一个并发槽。
- 降低目标并发时不会强行停止已经运行的任务，只会暂缓后续补位。
- 并发功能同时支持 QSV、NVENC 与 AMF，不限定 NVIDIA 显卡。

并发优化针对的是**整批文件的总吞吐量**。显卡性能强、编码会话与显存充足时，多路任务通常能缩短整个批次的完成时间；单个视频本身不一定会更快。

### 自动动态并发

自动模式只统计正式 FFmpeg 编码阶段的 `speed=x`，不会把 ab-av1 探测速度混入吞吐量比较。

- 前 `60` 秒用于预热，随后使用 `90` 秒稳定窗口观察吞吐量。
- 从 `N` 路提升到 `N+1` 路后，总吞吐量至少提高 `15%` 才会保留新级别。
- 提升收益不足时会回退，并在当前批次中停止继续尝试更高等级。
- CPU 持续高占用、可用内存过低、吞吐量明显下降或出现硬件资源耗尽错误时，会降低后续目标并发。
- 自动调整后有冷却期，避免并发数量频繁来回波动。

### 批次调度与进度

- 每个文件由独立 Worker 处理，调度器负责启动、补位、暂停、停止与完成汇总。
- 总体进度优先按视频时长加权；缺少时长时使用批次已知时长的中位数。
- ab-av1 探测映射到文件进度的前 `15%`，正式编码映射到后 `85%`。
- 界面显示当前目标并发、活动任务、排队任务和等待错误处理任务数量。

### 错误队列

- 失败文件会停止子进程并释放并发槽，其他文件可以继续运行。
- 多个错误按发生顺序进入 FIFO 队列，界面一次只显示一个错误对话框。
- 30 秒没有操作时自动跳过当前错误文件。
- 选择停止会终止整个批次；重复错误事件不会重复弹窗。

### 独立缓存与输出保护

每个批次与文件都有独立临时目录：

```text
缓存目录/
  mgw-session-<批次ID>/
    task-<任务ID>/
      ab-av1/
      output.temp.mkv
```

- Worker 只清理自己的任务目录，不再扫描并删除公共缓存根目录中的临时文件。
- 启动前统一计算所有最终输出路径。
- 如果多个输入会写入同一个目标文件，批次会在开工前停止并显示冲突，避免并发覆盖。

## NVIDIA 远程桌面稳定性

- NVENC 模式不再使用可能自动选择 DXVA2 的 `-hwaccel auto`。
- 硬件解码优先显式使用 CUDA，不依赖远程桌面图形会话中的 Direct3D 设备。
- RDP 锁屏或断开后，不再因为 `Failed to create Direct3D device` 直接中止。
- CUDA 硬件解码初始化失败时，只对当前文件回退到 CPU 软件解码，视频编码仍使用 NVENC。

CPU 解码回退**不会主动修改 VMAF、CQ、预设、10-bit、AQ 等编码质量参数**，因此不会因为回退本身降低目标编码质量。可能的代价是 CPU 占用增加、速度下降，以及在极端资源压力下整批吞吐量降低。

## 精确错误降级

每个文件最多进行三次互不重复的最终转码尝试：

1. 使用首选硬件解码并保留字幕。
2. 只有硬件解码设备错误时，回退 CPU 解码。
3. 只有日志明确指向字幕流损坏或不兼容时，丢弃字幕。

两类错误按实际发生顺序组合，不会把未知错误、权限错误、输出路径错误或硬件错误误报为字幕损坏。无法识别的错误会保留真实 FFmpeg 日志并停止当前文件，不盲目重试。

## ab-av1 可靠性修复

- 不再把单个采样片段的 VMAF 当成完整 CRF 结果。
- 每个 CRF 只显示一次正式汇总，减少重复刷屏。
- 正常成功必须同时满足退出码为 `0` 和正式 `crf X successful` 标记。
- 只有明确的“目标 VMAF 与体积限制无法同时满足”才进入画质优先后备。
- 后备会选择达到目标 VMAF 的最大 CRF，并显示预测体积警告。
- 所有探测器失败或没有候选达到目标 VMAF 时，不再强制采用最后样本或默认 CRF 24。

## 配置说明

主界面新增：

- **转码并发模式**：自动动态调节 / 手动固定。
- **手动并发数**：`1–4`，仅手动模式可编辑。

默认使用自动模式。对显存较少、CPU 较弱或驱动编码会话限制严格的设备，建议先使用自动模式；如需可预测的资源占用，可切换为手动 `1` 路或 `2` 路。

## 安装与升级

### 正式版

1. 下载 `MagicalGirlWorkshop_v1.4.0.zip`。
2. 解压到任意目录。
3. 双击 `MagicalGirlWorkshop.exe`。

### 源码运行

1. 安装 Python 3.12 与 `uv`。
2. 在项目目录执行 `uv sync`。
3. 确认 `tools/` 包含 `ffmpeg.exe`、`ffprobe.exe` 与 `ab-av1.exe`。
4. 执行 `uv run main.py`。
