v1.4.0 - ✨ 魔法少女工坊 (Magical Girl Workshop) v1.4.0 - 多重炼成，动态并发

> **"让强大的显卡同时照看多条炼成回路，也让每一次降级都有明确理由。"**

**魔法少女工坊 v1.4.0** 将无人值守稳定性修复与新的多文件并发架构合并发布。本次更新不仅修复了 NVIDIA 远程桌面锁屏后 DXVA2 设备失效、字幕错误误判和 ab-av1 临时结果误用，还加入了适用于 Intel QSV、NVIDIA NVENC 与 AMD AMF 的动态多路转码。

## 🎉 版本亮点 (Highlights)

*   **🔀 多路文件转码**: 
    *   手动模式支持固定 `1–4` 路并发。
    *   自动模式从 `1` 路开始，根据实际吞吐量与系统资源逐步尝试提升，最高 `3` 路。
    *   并发功能同时支持 QSV、NVENC 与 AMF，不限定 NVIDIA 显卡。
*   **📈 自动动态并发**: 
    *   自动模式只统计正式 FFmpeg 编码阶段的 `speed=x`，前 `60` 秒预热后使用 `90` 秒稳定窗口观察。
    *   提升后总吞吐量至少提高 `15%` 才会保留新级别。CPU 高占用、内存低或吞吐量下降时会自动降低并发。
*   **⏱️ 批次调度与进度**: 
    *   每个文件由独立 Worker 处理，进度优先按视频时长加权（ab-av1 15%，正式编码 85%）。
    *   界面实时显示当前目标并发、活动任务、排队任务和等待错误处理任务数量。
*   **⚠️ 错误队列**: 
    *   失败文件会停止子进程并释放并发槽，其他文件继续运行。多个错误按发生顺序进入 FIFO 队列，30 秒无操作自动跳过。
*   **🛡️ 独立缓存与输出保护**: 
    *   每个批次与文件都有独立临时目录。Worker 只清理自己的任务目录。启动前检测输出冲突，避免并发覆盖。
*   **💻 NVIDIA 远程桌面稳定性**: 
    *   优先显式使用 CUDA 硬件解码，不依赖 `-hwaccel auto`。彻底解决 RDP 锁屏或断开后 `Failed to create Direct3D device` 导致的崩溃。CUDA 失败仅回退当前文件 CPU 软件解码。
*   **🎯 精确错误降级**: 
    *   每个文件最多进行三次互不重复的尝试（首选 -> 回退 CPU 解码 -> 丢弃字幕）。无法识别的错误保留日志并停止，不盲目重试。
*   **🔧 ab-av1 可靠性修复**: 
    *   不再把单个采样片段的 VMAF 当成完整 CRF 结果。只有明确“目标 VMAF 与体积限制无法同时满足”才进入画质优先后备。

## 🚀 更新日志 (Changelog)

*   [New] **多路转码并发**: 新增针对 QSV、NVENC、AMF 的动态多路转码支持（自动/手动模式）。
*   [New] **独立缓存架构**: 为每个任务划分独立的缓存目录（`mgw-session-xxx`），隔离临时文件。
*   [New] **FIFO 错误队列**: 引入全新的错误处理队列，支持 30 秒自动跳过。
*   [New] **配置项更新**: 界面新增“转码并发模式”及“手动并发数”配置。
*   [Fix] **NVIDIA 远程桌面锁屏崩溃**: 修复了由于 RDP 断开导致 DXVA2 设备不可用而中断整批转码的问题。
*   [Fix] **精确重试降级**: 重构失败重试逻辑，硬件解码错误与字幕兼容性错误被精确分离。
*   [Fix] **ab-av1 误判修复**: 修复探测器将单个片段视为成功的问题，并改进了后备策略逻辑。

## 📥 部署指南 (Installation)

### 方式一：下载正式版 (推荐)

*   **安装包 (Setup)**: 下载本页面下方的 `MagicalGirlWorkshop-v1.4.0-Setup.exe`，双击运行并按提示完成安装。
*   **便携版 (Portable)**: 下载 `MagicalGirlWorkshop-v1.4.0-Portable.7z`，解压至任意目录，双击 `MagicalGirlWorkshop.exe` 即可直接使用。

### 方式二：源码运行 (Dev)

1.  **环境**: 安装 Python 3.12 与 `uv`。
2.  **依赖**: 在项目目录执行 `uv sync`。
3.  **工具**: 确认 `tools/` 包含 `ffmpeg.exe`、`ffprobe.exe` 与 `ab-av1.exe`。
4.  **启动**: 执行 `uv run main.py`。
