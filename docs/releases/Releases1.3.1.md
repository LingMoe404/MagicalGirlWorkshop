v1.3.1 - 🛡️ 魔法少女工坊 (Magical Girl Workshop) v1.3.1 - CUDA 守护，远程不眠

> **“即使观测者离开视界，炼成回路也将继续运转。”**

**魔法少女工坊 v1.3.1** 是一次专注于 NVIDIA 无人值守转码稳定性与 VMAF 探测可靠性的修复版本。本次更新解决了 Windows 远程桌面（RDP）锁屏或断开后，FFmpeg 因 DXVA2 无法创建 Direct3D 设备而中止的问题，并重构了最终转码阶段的错误判断、自动降级和 ab-av1 结果解析流程。

## 🎉 版本亮点 (Highlights)

*   **🛡️ CUDA 解码守护**:
    *   NVIDIA NVENC 模式不再使用 `-hwaccel auto`。
    *   硬件解码明确指定为 CUDA，避免 FFmpeg 自动选择依赖桌面图形会话的 DXVA2。
    *   远程桌面锁屏或断开后，转码不再因为 DXVA2 Direct3D 设备消失而直接失败。
*   **🔄 智能解码降级**:
    *   如果 CUDA 硬件解码确实初始化失败，程序只对当前文件自动切换为 CPU 软件解码。
    *   视频编码仍然使用 `av1_nvenc`，原有 CQ、预设、10-bit 像素格式与 AQ 参数保持不变。
    *   降级可能增加 CPU 占用或降低速度，但不会因为降级而修改目标编码质量参数。
*   **📝 精确字幕诊断**:
    *   只有 FFmpeg 日志明确指向字幕流损坏、解码失败或格式不兼容时，程序才会丢弃字幕重试。
    *   硬件设备、文件权限、输出路径等其他错误不再被误报为字幕损坏。
*   **🧪 三阶段安全重试**:
    *   每个文件最多执行三次互不重复的转码尝试。
    *   支持按照真实错误顺序组合“硬解转软解”和“保留字幕转无字幕”两种降级。
    *   无法识别的错误立即停止当前文件并保留真实 FFmpeg 日志，不再盲目重试。
*   **📊 可信的 VMAF 探测结果**:
    *   单个采样片段的 VMAF 只用于内部诊断，不再被误认为完整视频的 CRF 结果。
    *   每个 CRF 只显示一条汇总 VMAF 与预测体积，避免同一 CRF 连续刷屏。
    *   正常成功必须同时满足 ab-av1 退出码为 `0`，并输出正式的 `crf X successful` 标记。
*   **⚖️ 画质优先后备**:
    *   如果 ab-av1 明确报告 `Failed to find a suitable crf`，程序会检查完整汇总候选。
    *   当某些候选达到目标 VMAF、但超过默认 80% 预测体积限制时，选择达到目标 VMAF 的最大 CRF，并显示汇总 VMAF 与预测体积警告。
    *   如果没有候选达到目标 VMAF，或发生设备、编码器、输入等其他异常，则停止当前文件，不再强行采用最后样本或默认 CRF 24。

## 🚀 更新日志 (Changelog)

*   [Fix] **RDP 锁屏转码中止**: 修复 NVIDIA 模式下 `-hwaccel auto` 自动选择 DXVA2，导致远程桌面锁屏或断开后出现 `Failed to create Direct3D device` 的问题。
*   [Fix] **字幕错误误报**: 修复任意 FFmpeg 错误都会触发“丢弃字幕重试”的错误行为。
*   [Opt] **CUDA 优先**: NVENC 最终转码阶段使用显式 CUDA 硬件解码。
*   [Opt] **软件解码后备**: 硬件解码设备失败时，仅对当前文件切换 CPU 解码，NVENC 编码和画质参数不变。
*   [Test] **降级策略测试**: 新增硬件错误、字幕错误、未知错误和两种错误顺序的自动化回归测试。
*   [Fix] **ab-av1 样本日志刷屏**: 只显示每个 CRF 的汇总 VMAF，不再显示每个采样片段的临时 VMAF。
*   [Fix] **Code 1 强行采用临时 CRF**: 只有明确的“VMAF 与体积限制无解”错误才能进入画质优先后备；其他错误继续下一个探测器。
*   [Fix] **默认 CRF 24 兜底**: 所有探测器失败时停止当前文件并显示真实诊断，不再使用任意默认值开始编码。
*   [Test] **真实 ab-av1 0.10.4 冒烟测试**: 验证无 `-v` 模式仍会输出正式成功标记，并覆盖重复汇总、无解后备和未知错误。

## ⚙️ 适格者要求 (Requirements)

*   **OS**: Windows 10 / 11。
*   **NVIDIA AV1 GPU**: GeForce RTX 40 系列或其他支持 AV1 NVENC 的 NVIDIA 显卡。
*   **Driver**: 建议安装支持当前 FFmpeg CUDA/NVENC 接口的 NVIDIA 驱动。

## 📥 部署指南 (Installation)

### 方式一：下载正式版

1. 下载 `MagicalGirlWorkshop_v1.3.1.zip`。
2. 解压至任意目录。
3. 双击 `MagicalGirlWorkshop.exe`。

### 方式二：源码运行

1. 使用 Python 3.12 与 `uv` 安装依赖：`uv sync`。
2. 确认 `tools/` 目录包含 `ffmpeg.exe`、`ffprobe.exe` 和 `ab-av1.exe`。
3. 执行 `uv run main.py`。
