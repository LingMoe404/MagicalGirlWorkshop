# “羁绊之证”纪念卡精简设计

## 背景

当前“羁绊之证”页面将 lose2me（REwaTLE）的帮助拆成六项技术贡献。随着项目持续迭代，这些内容已经更接近早期学习经历，而不是当前技术能力的完整来源。

页面应继续表达对朋友早期启蒙的感谢，但不再把已经掌握并继续发展的旧方法展示成当前项目的技术履历。

## 设计目标

- 保留“羁绊之证”页面名称和纪念意义。
- 保留 lose2me（REwaTLE）的署名、GitHub 与 Bilibili 链接。
- 将关系定位从具体技术贡献者调整为“启蒙协力”。
- 用温和的文字表达早期帮助与后续独立成长。
- 删除六项旧技术贡献卡片，降低页面信息密度。
- 避免与主界面页脚重复展示技术栈和 AI 协作署名。

## 页面结构

页面继续沿用现有导航入口、语言选择器和主题选择器。

主体由一张纪念卡组成：

1. 显示 `lose2me (REwaTLE)`。
2. 显示角色“启蒙协力”。
3. 显示两段式感谢文案。
4. 保留 GitHub 与 Bilibili 按钮。

不再显示六宫格技术贡献列表，也不再显示卡片底部的技术栈和 AI 协作署名。

## 简体中文文案

角色：

> 启蒙协力

正文：

> 感谢在工坊早期分享开发经验与工具链思路。
>
> 那些最初的指引，已经成为独立探索更强术式的起点。

文案不直接使用“超越”“淘汰”或“更先进”等比较性表达，以免削弱感谢本身。

## 多语言

简体中文、繁体中文、英文和日文保持相同含义：

- 感谢早期分享的开发经验和工具链思路。
- 表达这些指引成为后来独立探索的起点。
- 不暗示对方仍负责当前项目技术方向。
- 不使用贬低旧方法或比较双方能力的措辞。

删除不再使用的六组贡献标题与描述翻译键，以及卡片页脚翻译键。保留页面标题、角色和正文翻译键。

## 代码调整

- 精简 `CreditsInterface`，移除贡献网格、贡献数据和对应的重翻译循环。
- 保留现有卡片、姓名、社交按钮、语言切换和主题切换逻辑。
- 调整正文标签以支持两行文案和合理换行。
- 同步清理四种语言文件中的废弃键。

不新增配置项、数据模型或外部依赖。

## 验证

- 运行语言文件语法与键一致性检查。
- 离屏初始化主窗口，确认“羁绊之证”页面可正常创建。
- 确认姓名、角色、感谢正文及两个社交按钮仍存在。
- 确认六项贡献卡片和旧卡片页脚已移除。
- 运行现有自动化测试，防止界面初始化和翻译逻辑回归。

## 非目标

- 不更改朋友的姓名或社交主页地址。
- 不删除“羁绊之证”导航入口。
- 不在本页面新增作者、开源项目或 AI 模型名单。
- 不修改 README 中现有的项目致谢与 AI 协作说明。
